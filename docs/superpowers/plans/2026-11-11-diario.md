# Diário da campanha: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** caderno do mestre com entradas livres por etiqueta, que ele libera uma a uma para os jogadores lerem (sem a nota secreta).

**Architecture:** `game.journal` vive no servidor e vai no arquivo de sessão, mas **não** no `state:full`: segue o padrão do `handout` (versão no `Store` + evento `journal`), filtrado por jogador em `journalFor` (`view.ts`). No cliente, o diário fica no `useApp`, fora do `ClientState`; painel na aba *Mesa*, janela única (edição para o mestre, leitura para o jogador) e botão no topo.

**Tech Stack:** TypeScript, Express + Socket.IO, node:test, React + Mantine + Zustand.

**Spec:** [docs/design/diario.md](../../design/diario.md)

## Global Constraints

- Ações só do mestre (`requireGm`); validar tudo antes de alterar o estado; recusas com `fail()` em português como modelo (`fail("… {n}.", { n })`), traduzidas em `client/src/i18n/serverText.ts`.
- Limites em `LIMITS`: `journal: 200`, `journalTitle: 80`, `journalText: 4000`, `journalNote: 2000`.
- Etiquetas: `session`, `quest`, `npc`, `place`, `other`. `done` só em `quest`.
- O jogador nunca recebe `note` nem entrada sem `shared`; o diário nunca aparece no `state:full`.
- Interface só com Mantine e o tema (ADR-15, guia visual); ícones Tabler; textos novos em `pt-BR.ts`, `en.ts`, `es.ts` (chaves `journal.*`); jogador cabe em 375 px.
- Formato do arquivo de sessão continua 2; arquivo sem `journal` abre com o diário vazio.
- **Sem commits do agente:** no fim de cada tarefa, parar, mostrar o resumo e esperar o Jorge validar e commitar.
- Fechar cada tarefa com `npm run typecheck` e `npm test` verdes.

## Review Focus

1. **"Não salvo" ignorando o diário:** o `snapshot` de `client/src/sessionFile.ts` só olha `templates/allies/battle/log`; mexer no diário tem que acender o *Não salvo* (Tarefa 5).
2. **Entrada recolhida com a janela do jogador aberta nela:** a janela volta para a lista sem quebrar (Tarefa 7).
3. **Primeira chegada do diário** (entrar, reconectar, mestre carrega arquivo): não dispara um toast por entrada antiga; só a bolinha (Tarefa 7).
4. **Carregar sessão de arquivo:** todos recebem o diário novo, inclusive quem já estava conectado (Tarefa 4).
5. **Texto longo sem espaço** (URL, "aaaa…") em 375 px: quebra a linha em vez de vazar (`overflow-wrap: anywhere`) (Tarefa 7).
