# Vento nas plantas — plano

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Árvore, arbusto e flores balançando com o vento no mapa, mais três plantas novas (pinheiro, palmeira, grama alta) e o conjunto *Campo* no pincel.

**Architecture:** As contas puras do vento (força pelo clima, rajada que atravessa o mapa, detector de aparelho que não aguenta) ficam em `shared/src/wind.ts`, com teste. O desenho das plantas passa a pintar em três alvos (sombra, copa de baixo, copa de cima): parado, os três são o mesmo canvas (desenho idêntico ao de hoje); com vento, são três imagens em cache. No mapa, cada planta vira um `Group` de três `Image` mexidos por um `Konva.Animation` por camada de objetos (abordagem A do desenho).

**Tech Stack:** TypeScript, React, react-konva, Canvas 2D, node:test.

**Spec:** [docs/design/vento.md](../../design/vento.md) (referência visual: [docs/design/vento-teste.html](../../design/vento-teste.html))

## Global Constraints

- As árvores, arbustos e flores que já estão nos mapas saem iguais aos de hoje, parados (mesma semente = mesmo desenho). A escolha das folhas que piscam usa um sorteio à parte, nunca o do desenho.
- O vento é do mapa: não gira com o objeto. Nada vai pela rede; cada tela calcula pelo relógio.
- Brisa sempre (força 1). Climas `leaves`, `blizzard`, `sand`, `storm`: força `1 + intensity`. Direção: `wind < 0` → para a esquerda; senão para a direita.
- Parado (uma imagem, como hoje) quando: *Reduzir efeitos*, ferramenta Objetos ativa, ou o aparelho não aguentou (detector).
- Animação a no máximo 30 quadros por segundo; cogumelos não balançam.
- Sem `any` nem cast forçado; nomes com significado; comentários e textos em português; texto novo de interface em `pt-BR.ts`, `en.ts` e `es.ts`.
- O cliente não tem teste automático: a prova do cliente é `npm run typecheck` e o navegador (`npm run dev`, galeria no mapa), aprovado pelo dono. Contas puras e servidor: `npm test`.
- Nada de commit pelo agente: no fim de cada tarefa, sugerir o commit (`git add` + `git commit -m "Vento: …"`) e esperar o "segue".

## Review Focus

1. Mapa salvo antes: árvores, arbustos e flores com o mesmo desenho, parados e na imagem do vento juntada (Task 2, comparação de pixels).
2. Objeto girado (90°, 180°): balança na mesma direção que o vizinho sem giro (Task 3, navegador).
3. Floresta grande (300 árvores) e zoom mudando de degrau: sem engasgo, sem quadro em branco enquanto a imagem nova é feita (Task 3, navegador).
4. Token embaixo da copa: a copa animada fica meio transparente como hoje (Task 3, navegador).
5. Aba que volta do segundo plano (um quadro de vários segundos): o detector não desliga o vento por isso (Task 1, teste).

### Task 1: Contas do vento

**Files:**
- Create: `shared/src/wind.ts`
- Modify: `shared/src/index.ts` (exportar)
- Test: `server/test/wind.test.ts`

**Interfaces:**
- Produces:
  - `windOf(weather: WeatherState | null): { strength: number; direction: 1 | -1 }`
  - `gust(t: number, col: number, row: number, seed: number, direction: 1 | -1): number` — `t` em segundos, posição em casas; soma de senos do teste (`sin(travel*0.9)*0.55 + sin(travel*2.3+seed)*0.25 + sin(travel*4.1+seed*2)*0.1`), com `travel = t - direction*col/8 - row/20`. Resultado entre -0,9 e 0,9.
  - `class FrameWatch { tick(frameMs: number): boolean }` — `false` a partir do momento em que o aparelho "não aguentou" (e continua `false`). Regra: numa janela de 3 s de quadros, mais da metade com mais de 50 ms. Quadros acima de 1000 ms (aba voltando) são ignorados.

- [ ] **Step 1: Escrever os testes em `server/test/wind.test.ts`**

```ts
describe("vento: contas", () => {
  it("brisa sem clima, mais forte em clima de vento", () => {
    assert.deepEqual(windOf(null), { strength: 1, direction: 1 });
    assert.deepEqual(windOf(weather({ kind: "rain", intensity: 1, wind: 20 })), { strength: 1, direction: 1 });
    assert.deepEqual(windOf(weather({ kind: "leaves", intensity: 0.6, wind: -30 })), { strength: 1.6, direction: -1 });
    for (const kind of ["blizzard", "sand", "storm"] as const) assert.equal(windOf(weather({ kind, intensity: 1, wind: 0 })).strength, 2);
  });
  it("a rajada anda 8 casas por segundo no sentido do vento", () => {
    assert.ok(Math.abs(gust(3, 2, 5, 7, 1) - gust(4, 10, 5, 7, 1)) < 1e-9);
    assert.ok(Math.abs(gust(3, 2, 5, 7, -1) - gust(4, -6, 5, 7, -1)) < 1e-9);
  });
  it("a rajada fica entre -0,9 e 0,9", () => {
    for (let t = 0; t < 60; t += 0.37) assert.ok(Math.abs(gust(t, t * 3, t, 11, 1)) <= 0.9 + 1e-9);
  });
  it("detector: 30 quadros por segundo aguenta; 12 por segundo não", () => {
    const smooth = new FrameWatch();
    for (let i = 0; i < 300; i++) assert.equal(smooth.tick(33), true);
    const slow = new FrameWatch();
    let ok = true;
    for (let i = 0; i < 60; i++) ok = slow.tick(80);
    assert.equal(ok, false);
    assert.equal(slow.tick(16), false, "desligado continua desligado");
  });
  it("detector: um quadro enorme (aba voltando) não desliga", () => {
    const watch = new FrameWatch();
    for (let i = 0; i < 100; i++) watch.tick(33);
    assert.equal(watch.tick(5000), true);
    for (let i = 0; i < 100; i++) assert.equal(watch.tick(33), true);
  });
});
```

- [ ] **Step 1: Planta animada**

Senão, o `PropNode` de hoje, sem mudança.

- [ ] **Step 2: O relógio do vento**

Um `Konva.Animation` por `MapPropLayer`, ligado só se a camada tem planta animada. A cada quadro (pula e devolve `false` se passaram menos de 33 ms desde o último): `t = agora/1000`; para cada planta visível (dentro da visão do palco, com folga de 2 casas), com `g = gust(t, col, row, seed, direction) * strength` e `lag = gust(t - 0.25, …) * strength`, em casas e no espaço do mapa (o `Group` não gira):
- `shadow`: desloca `(g*0.021, g*0.009)`, gira `g*0.01` rad;
- `low`: desloca `(g*0.035, g*0.012)`, gira `g*0.018` rad;
- `high` e as folhas: desloca `(lag*0.06, lag*0.021)`, gira `lag*0.03` rad;
- deslocamento em x multiplicado por `direction`; giro somado ao `p.rotation`;
- folha que pisca: alpha `max(0, sin(t*speed+phase))^6 * (0.35 + |g|*0.5)`, cor `#b5dc78`, elipse girando `turn + pulso*0.6`.
Nenhuma planta visível: devolve `false` (sem redesenhar). O tempo de cada quadro vai para um `FrameWatch`; quando ele devolve `false`, `useApp.setState({ windStalled: true })` (as plantas voltam a ser uma imagem só, até recarregar a página).
